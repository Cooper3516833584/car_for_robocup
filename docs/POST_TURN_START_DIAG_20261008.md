本机 `C:/Users/TZDEZACR/Desktop/cccccar/` 下厂商资料的
`5.STM32源码/LD14雷达/` 包含库函数与HAL两套源码。
HAL包 `L150-避障巡线雷达小车-C10B-HAL库-20260525.zip` 的SHA256为
`04856f6ca7b113b8b569f6212abf628e78e6b9b5a8523c5a7ca9baee187b2671`。
两套源码的 `CONTROL/pid.c` 内 `Incremental_PI_Left/Right` 各自使用
静态 `Pwm/Last_bias`，更新式为 `Pwm += Kp*(Bias-Last_bias)+Ki*Bias`，
没有零目标/静止状态专用重置分支，函数内PWM限幅是注释；
`CONTROL/control.c` 只在函数返回并经滑动均值后限幅输出。
这会保留控制历史，也存在内部状态超过输出限幅的可能。
目标和反馈均为零且 `Last_bias` 为零时，继续零速不会改变残留 `Pwm`。

这些是资料源码中的具体事实，尚不能证明本车烧录二进制与该源码完全一致，
也不能用现有遥测反推出实际PWM或宣称积分残留已是唯一根因。
接线与机械因素仍需区分；历史调试曾出现左轮间歇性无力，
本次不能直接沿用旧报告的接插件结论。
