# RoboCup 差速底盘实车测量记录

本表用于将来把 `configs/robocup_diffdrive.toml` 的软件测试占位值替换为本车实测值。下列现场初值尚未完成重复测量和动态复核，因此总表仍标为**未测量／未验证**。不要从示例 TOML 抄录数字作为测量结果。

## 2026-10-03 结构调整后的待复核初值

用户报告 T265 已移到车身左侧、沿主动轮轴线居中，外壳正装且镜头朝左；外壳内层和外层距主动轮轴线中点分别为 **167.8 mm**、**179.8 mm**。左右外壳若保持对称，车壳总宽初值为 **359.6 mm**。主动轮接触中心线轮距仍为 **200 mm**，与 C10B 固件协议换算轮距 **164 mm** 是不同参数，不能相互覆盖。场地右上角为原点、第一象限内约 6 m × 5 m，但墙边不保证正交；驱动标定只使用运动起点的相对位姿。

按当前安装描述和旧高度推算的 T265 跟踪原点初值为 `x=-0.00910 m`、`y=+0.17375 m`、`z=+0.03225 m`、`yaw=+π/2 rad`，roll/pitch 暂按 0。`y` 使用内层 167.8 mm 加相机背面到跟踪原点约 5.95 mm；`x` 使用旧记录的相机横向 9.10 mm 偏置经旋转后的估计。相机外壳实际朝向、内外层与镜头面的对应、`x` 偏置符号及高度都须在车上复核，尤其要手动绕轴线中点转车，检查补偿后中心轨迹。示例配置已写入这些**候选值**，`geometry_measured=false`、`sensor_extrinsics_measured=false` 保持不变；不得把本段视为实测验收。后续驱动标定方案见 `DRIVE_CALIBRATION_20261003.md`。

## 2026-10-02 短距联调现场初值（尚未通过动态复核）

用户确认雷达中心在地面的投影与主动轮轴线中点重合；两主动轮接触中心线间距为 **200 mm**，每只轮子的接触中心线距车辆中心线 **100 mm**（测量工具和重复次数待记录）。T265 外壳正装、左右居中、鱼眼朝车后；雷达中心到外壳近端与远端分别为 **24.8 cm** 和 **26.0 cm**，轴线中点到外壳下缘的竖直距离为 **2 cm**。安装 roll/pitch 暂按零，不作为已测角度。

按 Intel T265 [数据手册图 4-2](https://www.intel.com/content/dam/support/us/en/documents/emerging-technologies/intel-realsense-technology/IntelRealSenseTrackingT265Datasheet.pdf) 中的跟踪原点位置推算，仅供传感器探针验证的初值为：`x≈-0.254 m`、`y≈-0.0091 m`、`z≈0.03225 m`、`yaw≈π rad`。其中 x 使用外壳近端 24.8 cm 与背面至跟踪原点约 5.95 mm；y 使用外壳中心到内部模块中心约 9.10 mm；z 使用下缘高度 2 cm 与外壳半高 12.25 mm。这些推算值须通过手动绕轴旋转的原始相机／补偿中心轨迹核对；暂不设置 `geometry_measured` 或 `sensor_extrinsics_measured` 为 true。C10B 原地旋转能力和短距精度也尚未实车验证。

## 动态复核与变更追溯

- 有效轮距：用多个方向、速度下的原地旋转数据拟合，不能只用一次 90° 结果。
- 速度尺度：直行 1–2 m，左右方向和多个速度档分别记录命令距离、T265/D500 距离。
- 每次参数变更记录原值、新值、数据文件、日期、操作者和对应 Git commit。
- 未完成机械与传感器测量前，保持配置测量标记为 `false`；正式 `hardware-mission` 由运行时 readiness gate 拒绝启动。
