### 4.1 43/32 cm 进退的航向保持（F10，按操作者定义实现）

操作者要求：进退时让**车尾背后的那面墙与雷达正前方保持约 90°**，允许 ±5°，并在行进中动态纠偏。

实现与判据：车体正对参考墙时，该墙法向与车头方向平行，因此
`墙-车头夹角 = 90° - (实测墙方位 - 期望方位)`。所以直接用 `bearing - desired_bearing` 作为偏差量：

- `DROP_HEADING_BAND_RAD = 5°`（死区）：带内指令**恰好为零**，不做无谓抖动；
- 带外 `omega = k * (|error| - 5°)`，`DROP_HEADING_GAIN = 1.5`，再受底盘角速度上限与 `sqrt(2*a*error)` 制动形状限制，因此是"减速进入带内"而不是冲过带边；
- 平移**不停**（这是"行进中纠偏"），且不使用原地旋转——原地转需要一轮正反转，会与 C10B 倒车补偿和轮速速限幅相互干扰，而前进/倒车下的角速度偏移是纯差速，无需特例。

**到达距离本身不算成功。** 这是本轮额外发现并修掉的一个缺陷：原实现的成功出口只看距离，车即使歪 40° 到达目标距离也会报 `distance_reached`。现在要求**距离到位 且 航向在容差内**才成功；如果距离已经到位但航向仍在带外，则**原地只纠航向**（`v=0`、`omega=heading_command`、`action_state=waiting`），并由共享的超时上界兜底（转不动就失败，不会无限等待）。

- `DROP_HEADING_TOLERANCE_RAD = 5.5°`：**成功判据必须略宽于死区**。两者相等时控制器恰好在带边停止纠偏，残余若落在带边外一个纳弧度就永远不再被纠正，动作会卡在"差一点点成功"上（实测确实如此：停在 5.0000001°）。多出的 0.5° 是收敛余量，不是放宽允许量——纠偏仍然在 5.0° 开始。自定义死区时用 `HEADING_SETTLE_MARGIN_RAD` 自动加余量。

方位比较在入口方位所在的**坐标轴**上做解缠：`rho` 与法向在 `n -> -n` 下都不变，所以后方墙的存储方位可能报在 `+π` 一侧，那是同一面墙而不是 180° 航向误差。

离线实测（模拟底盘 + 再生墙观测，走真实 `MoveNormalToWall`）：

| 初始偏角 | 结果 | 角速度 |
|---|---|---|
| 0° | 保持 0°，距离 1.600 → 2.020 到位并成功 | 全程 0（不纠偏） |
| +10° | 纠到 **+5.0°** 后成功，距离到位 | 峰值 0.131 rad/s |
| −10° | 纠到 **−5.0°** 后成功 | 峰值 0.131 rad/s |
| +4°（带内） | 不纠偏，距离到位并成功 | 全程 0 |
| 距离到位但歪 30° | **不报成功**，原地纠航向（v=0，ω≠0） | 0.65 rad/s |
| 返程（−1）10° / 0° | 距离 2.030 → 1.610 到位，同上 | 同上 |

增益含义（现场若要调整）：`1.5` 使带外误差约 30° 时才触及底盘角速度上限 0.8 rad/s；偏小则纠不回来，偏大则在带边附近摆头。
